## Structure

Each folder matches a step of the A2Z sheet. Files are named like `two-sum.cpp`
and start with a header comment (problem link, approach, time and space complexity).
Start new solutions from `templates/template.cpp`.

## Run

```bash
g++ -std=c++17 file.cpp -o file
./file        # on Windows: file.exe
```
